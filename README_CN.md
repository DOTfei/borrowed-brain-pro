## 什么是 Borrowed Brain Pro？

Borrowed Brain Pro 不是一个“名人角色扮演”或“金句生成器”AI 技能。它是一个**决策智力系统 (Decision Intelligence System)**，通过有依据的思维视角、历史失败边界与多视角决策委员会，协助用户解决真实的商业、产品与开发难题。

| Borrowed Brain Pro 不是 ❌ | Borrowed Brain Pro 是 ✅ |
| :--- | :--- |
| 名人角色扮演或语气模仿 | 经过历史案例验证的思维模型 |
| 语气充能金句生成器 | 多视角冲突与共识分析面板 |
| 虚构 AI 人设聊天机器人 | 失败边界与盲点审计 |
| 沉浸式提示词游戏 | 48 小时内可执行的低成本验证实验 |

## 🛠️ 垂直场景：开发者决策板 (Builder Decision Board)

专为独立开发者、Indie Hacker 及产品创作者打造。

```bash
# 示例提示词
"我应该继续加功能 X 还是做核心 UI 减法？"
"我的 SaaS 产品增长停滞了，应该 Pivot 还是坚持？"
"用 Boardroom 模式分析我今天是否应该开始收费。"
```

### 内置思考视角

- 🍏 **[Steve Jobs 产品极简视角](lenses/steve-jobs-product-simplification.md):** 极简聚焦、砍掉 90% 功能、对 1000 个好想法说 No。
- 📐 **[Charlie Munger 逆向思维视角](lenses/charlie-munger-inversion-and-mental-models.md):** 逆向思考、排除沉没成本、认知偏误审计。
- 🚀 **[Paul Graham MVP 与用户验证视角](lenses/paul-graham-mvp-and-user-validation.md):** 快速上线、做不可扩展的事、直接获取用户反馈。
- 📈 **[Warren Buffett 护城河与资本分配视角](lenses/warren-buffett-capital-allocation.md):** 竞争护城河防御、工程资源的机会成本。
- ⚡ **[Reed Hastings 快速反馈与自我颠覆视角](lenses/reed-hastings-culture-and-fast-feedback.md):** 主动颠覆旧业务、上下文替代控制、极速迭代。
- 🌌 **[Sam Altman 指数规模与动能视角](lenses/sam-altman-scale-and-momentum.md):** 杠杆效应、动能优先、追求复利增长。

## 🔍 自指案例：用 Borrowed Brain 决定项目本身的战略

我们使用 Borrowed Brain Pro 分析了自身项目的定位难题：

> **困境：** Borrowed Brain Pro 应该扩展 50 个名人 Profiles 拼数量，还是聚焦于开发者决策智力系统？

- **Jobs 视角：** 拥有 50 个 Profile 只会让用户感到困惑。消除杂音，聚焦于帮独立开发者做决策。
- **Graham 视角：** GitHub 上已有大量开发者面临真实选择。做不可扩展的事，今天就发布 1 行命令安装包。
- **Munger 逆向视角：** 在语气模仿上与爆款单人技能竞争必败无疑。必须围绕决策日志与失败边界建立护城河。
