# Security Policy

## Reporting Vulnerabilities or Content Concerns

`borrowed-brain-pro` is a repository containing AI prompts, skill definitions, and public profile analytical frameworks.

If you discover a security issue, privacy violation, or an unsourced/private individual profile in this repository, please report it by emailing the maintainer directly at:

**`dotfei@users.noreply.github.com`**

Please include:
1. The specific file or profile involved.
2. A description of the issue or concern.
3. Any relevant context or supporting links.

We will review all reports within 48 hours and take appropriate action.
